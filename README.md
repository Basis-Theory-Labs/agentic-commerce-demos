# Agentic commerce demos

A growing collection of self-contained demos that show how to build with the
[Basis Theory agentic commerce](https://developers.basistheory.com/) APIs and
SDKs.

Each demo lives in its own folder, has its own `package.json`, and can be
run on its own.

| Demo | Description |
|---|---|
| [`travel-agent/`](./travel-agent) | Skyscanner-style chat assistant that searches flights, issues a single-use virtual card, and "books" the flight on a simulated airline checkout. Uses Elements + react-agentic. |

See each demo's `README.md` for setup instructions.
